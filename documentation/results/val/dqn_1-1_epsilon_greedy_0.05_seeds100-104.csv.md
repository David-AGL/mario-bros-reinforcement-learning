# `results/val/dqn_1-1_epsilon_greedy_0.05_seeds100-104.csv`

Tabla de validación del DQN con `prediction_mode=epsilon_greedy_0.05`.

Cada fila contiene una de las semillas `100–104`. `max_x` varía entre `312` y `899`, pero ninguna partida completó el nivel. El CSV permite calcular tablas comparativas por semilla y contrastar la política estocástica con la versión greedy.
