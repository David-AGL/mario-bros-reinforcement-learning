# `results/eval/dqn_1-1_greedy_seeds100-104.csv`

Tabla de episodios correspondiente al JSON del mismo nombre. Tiene cinco filas, una por semilla de evaluación `100–104`, y registra una política DQN `greedy` sobre `1-1`.

Todas las filas tienen `completed=0`, `max_x=312` y `truncated=0`. Las diferencias de `reward` y `elapsed_seconds` son pequeñas; `noop_used` cambia según la semilla y documenta la aleatoriedad inicial reproducible.

El archivo es la versión tabular para análisis con pandas; el JSON conserva además la configuración y el resumen agregado.
